# 🌿 Readoro

Reading Comprehension Performance Under Fixed and Adaptive Difficulty: A Simulation Study

## Live Demo

Rebuilt automatically on every push to `main`: **https://aonnoes.github.io/Readoro/**

## Running Locally

**Requirements:** Node.js 22.13 or later and Git.

1. Clone the repository:

   ```bash
   git clone https://github.com/Aonnoes/Readoro.git
   cd Readoro
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the local server:

   ```bash
   npm run dev
   ```

4. Open **http://localhost:3000** in your browser.

If error occurs or port 3000 is already in use, run the following in PowerShell:

```powershell
$env:PORT=3001
npm run dev
```

Then open **http://localhost:3001**

To stop the server, press `Ctrl + C` in the terminal.
